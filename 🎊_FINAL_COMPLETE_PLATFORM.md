## 🚀 **How to Use Your Platform**

### **Upload Dataset:**
```
1. Go to: http://localhost:5173/app/data
2. Click "New Dataset" (purple button)
3. Choose CSV/Excel/JSON file
4. Upload!

What happens:
- Saved to Supabase ✅
- Synced to Neo4j 🔵
- Relationships auto-created
- Knowledge graph updates
- Toast: "Synced to knowledge graph! 🔵"
```

### **View Knowledge Graph:**
```
1. Go to: http://localhost:5173/app/insights
2. Click "Knowledge Graph" tab
3. See your datasets connected!
4. Visual relationship graph
```

### **Train ML Models:**
```
1. Go to: http://localhost:5173/app/train
2. Click "TensorFlow" tab (Pro feature)
3. See upgrade prompt
4. Stripe checkout ready!
```
