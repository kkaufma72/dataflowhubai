Data Flow:
1. User uploads CSV via React frontend
2. FastAPI validates and stores in PostgreSQL
3. Kafka publishes data processing events
4. ML service trains model (stores in PostgreSQL)
5. Training metrics sent to InfluxDB + TimescaleDB
6. Lineage graph updated in Neo4j
7. Results cached in Redis
8. Model artifacts stored in MinIO
9. Prometheus scrapes metrics
10. Grafana displays dashboards
