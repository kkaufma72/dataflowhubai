## 🚨 Red Flags to Monitor

Watch for these warning signs:

### Churn Warning
- [ ] Churn rate >5%/month → Interview every churned user
- [ ] Multiple users churning for same reason → Fix immediately

### Conversion Warning
- [ ] Landing page conversion <3% → A/B test headline/CTA
- [ ] Free→Paid conversion <5% → Review onboarding flow
- [ ] High bounce rate (>60%) → Page speed or messaging issue

### Traffic Warning
- [ ] 90% direct traffic → SEO not working, need content
- [ ] Declining week-over-week → Need new acquisition channels
- [ ] Low time on site (<1 min) → Content not engaging
