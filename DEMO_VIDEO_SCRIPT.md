## 🎨 Visual Guidelines

### Color Scheme (Match Landing Page)
- **Primary**: #4F46E5 (Indigo)
- **Secondary**: #10B981 (Green)  
- **Background**: White or light gray
- **Text**: Dark gray (#1F2937)

### Text Overlays
**Use Sparingly** - Only for emphasis:
- Quality Score: 87/100
- 94.3% Accuracy
- No Code Required
- Under 3 Minutes

**Font**: 
- Bold, sans-serif (Arial, Helvetica)
- Large enough to read on mobile
- Contrast against background

### Cursor Movement
- **Slow and deliberate** (people need to follow)
- Highlight clicks with cursor animation (OBS plugin)
- Pause 1-2 seconds after each action

### Pacing
- Speak clearly and at moderate speed
- Pause after key points (let them sink in)
- Show loading states briefly (2-3 sec max)

## 🎙️ Recording Tips

### Audio
**Critical**: Good audio > Good video
- Use external microphone if possible (Blue Yeti, Rode)
- Quiet room (turn off AC, fans)
- Record sample, listen back before full take
- Speak 10% slower than normal conversation
- Energy and enthusiasm (smile while talking!)

### Video
- 1920x1080 resolution minimum
- 30fps or 60fps
- MP4 format for YouTube upload
- Keep file under 500MB if possible

### Takes
- **Do 2-3 takes** - Use the best one
- If you mess up, pause 3 seconds, start section again
- You can edit mistakes out later

### Practice
- **Rehearse 3 times** before recording
- Time yourself (should be 2:50-3:00)
- Have script open on second monitor

## 🆘 Troubleshooting

### "I sound awkward on camera"
- Normal! Everyone does at first
- Do 3 practice takes (don't save them)
- Pretend you're explaining to a friend
- Smile while talking (really helps energy!)

### "My demo data looks boring"
- Use customer churn example (universally understood)
- Make numbers interesting: "94.3% accuracy" not "94%"
- Show real insights, not Lorem Ipsum

### "Video file is huge (>1GB)"
- Export settings: H.264 codec, 1080p, 30fps
- Use Handbrake (free) to compress
- Target: 50-100MB for 3 min video

### "I don't have a good microphone"
- iPhone/smartphone headphones work great!
- Record in small room (less echo)
- Put blankets around for sound dampening
